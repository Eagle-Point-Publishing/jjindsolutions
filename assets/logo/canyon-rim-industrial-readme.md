# Canyon Rim Industrial Logo Assets

Unused logo concept from an earlier name exploration. These files are not the J&J Industrial Solutions logo and are not used on the site.

## Files

- `canyon-rim-industrial-mark.svg` — square avatar/app/favicon source mark.
- `canyon-rim-industrial-horizontal.svg` — horizontal lockup for light backgrounds.
- `canyon-rim-industrial-horizontal-dark.svg` — horizontal lockup for dark backgrounds/site header.
- `canyon-rim-industrial-mark-2048.png` — transparent 2048x2048 PNG export.
- `canyon-rim-industrial-horizontal-2400.png` — transparent 2400x720 PNG export for light backgrounds.
- `canyon-rim-industrial-horizontal-dark-2400.png` — transparent 2400x720 PNG export for dark backgrounds.

## Notes

- Brand orange: `#f0731f`.
- Charcoal: `#14161a`.
- The mark is a canyon-rim silhouette with a river-cut notch, not a literal mountain peak.
- SVG text uses Barlow Condensed when available and falls back to condensed system display fonts.
- Best small-size use: square mark alone, or dark horizontal lockup at 220px+ wide.
